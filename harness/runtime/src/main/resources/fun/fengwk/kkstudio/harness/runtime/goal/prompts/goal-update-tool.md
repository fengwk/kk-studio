将当前 goal 更新为 `complete` 或 `blocked`。每次更新都必须提供非空的 `reason`，其中包含详细依据和具体证据：对于 `complete`，指出已经满足的要求及支持性证据；对于 `blocked`，指出重复出现的阻塞条件、已经进行的尝试，以及所需的用户输入或外部变更。只有当现有证据证明 objective 确实完成时，才设置 `complete`：objective 的每项要求都已满足，且没有遗留的必要工作。只有当同一阻塞条件连续至少三个 goal turn 重复出现，并且没有用户输入或外部状态变更就无法继续取得有意义的进展时，才设置 `blocked`。在 `budget_limited` 收尾期间只允许设置 `complete`；否则保持 goal 为 `budget_limited`。不要使用此工具暂停、恢复、清除或限制 goal 的预算。
